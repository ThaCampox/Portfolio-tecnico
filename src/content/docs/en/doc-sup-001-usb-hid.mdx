## 01. Identification

- **Procedure:** USB and HID device diagnostics.
- **Category:** IT Support, sub-category peripherals.

- **Version:** 1.0.

## 02. Objective and scope

**Problem:** a keyboard, mouse or other USB peripheral does not respond or is not recognized.

**In scope:** listing present devices, reading the Plug and Play status, checking the problem code and reviewing recent events.

**Out of scope:** hardware repair, peripheral firmware and USB blocking policies.

## 03. Technical environment

| Item | Value |
| --- | --- |
| Operating system | Windows 11 (state version and build) |
| Shell | Windows PowerShell 5.1 |
| Module | PnpDevice (built into Windows) |

## 04. Prerequisites

- A PowerShell session. The read-only commands work without elevation.
- No command in this procedure changes the system.
- Note the device and the port it was plugged into before you start.

## 05. Technical procedure

```mermaid
flowchart LR
  A[1 Identify] --> B[2 Investigate]
  B --> C[3 Diagnose]
  C --> D[4 Apply fix]
  D --> E[5 Validate]
```

### Step 1: identification

Confirm the symptom: which device, which port, since when. Try the same port with another peripheral and the same peripheral on another port.

### Step 2: investigation

List the USB and HID devices that are present:

```powershell
Get-PnpDevice -Class USB, HIDClass -PresentOnly |
  Select-Object Status, Class, FriendlyName, InstanceId |
  Sort-Object Class, FriendlyName |
  Format-Table -AutoSize
```

### Step 3: diagnosis

Filter what is not OK and read the problem code:

```powershell
$problems = Get-PnpDevice -PresentOnly | Where-Object Status -ne 'OK'
$problems | ForEach-Object {
  [pscustomobject]@{
    Name   = $_.FriendlyName
    Status = $_.Status
    Code   = (Get-PnpDeviceProperty -InstanceId $_.InstanceId -KeyName 'DEVPKEY_Device_ProblemCode').Data
  }
}
```

Check the device configuration events:

```powershell
Get-WinEvent -LogName 'Microsoft-Windows-Kernel-PnP/Configuration' -MaxEvents 20 |
  Select-Object TimeCreated, Id, Message
```

### Step 4: applying the fix

Apply one action at a time, from least to most invasive: switch ports, unplug and replug, update the driver from the vendor, restart the computer.

### Step 5: validation

Run the Step 2 command again and confirm the OK status. Test the device in real use (typing, moving the mouse).

## 07. Troubleshooting

| Symptom | Possible cause | Alternative |
| --- | --- | --- |
| Device disappears from the list | Cable, port or power | Another port, another cable, direct connection (no hub) |
| Error status with a code | Missing or corrupted driver | Reinstall the vendor driver |
| Works on another port | Faulty port or controller | Check the USB controller and power |

## 08. Risks and rollback

- The diagnostic commands are read-only.
- Uninstalling a driver can leave the peripheral unavailable until it is reinstalled. Note the current version first.
- If a problem appears after a driver update, use the roll back driver option in the device properties.
